Металлорукава серии Н8Д0.449.020 - металлорукава высокого давления с типом оболочки РГТ (рукава герметичные со спиральным гофром из цельнотянутых труб), с арматурой под приваркой.

Для изготовления заготовки оболочки типа РГТ толщина материала 0,2 -0,3 мм, используется труба, сформированная из тонкой стальной ленты и сваренная встык по всей длине аргонодуговой сваркой. Гофрирование трубы производится методом наружной обкатки профильными формующими кольцами по винтовой линии. Для повышения несущей способности во впадину гофра может укладываться спираль из высокопрочной нержавеющей проволоки.
